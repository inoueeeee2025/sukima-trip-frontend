# Sukima Trip Assets

Figma assets are organized by screen and state. File names use lowercase English with hyphens.

## Home

### `home/map1`

Home(map) normal state assets.

- `map-background.png`: Map background image.
- `coin-icon.png`: Coin icon image.
- `coin-badge.png`: Coin badge background image.
- `explore-icon.png`: Explore mode icon image.
- `explore-character.png`: Explore character/body image.

### `home/map2`

Home(map) measuring or dialog state assets.

- `measuring-icon.png`: Small measuring-state icon.
- `footprint-icon.png`: Footprint stamp icon.
- `measuring-dialog.png`: Measuring dialog image.

### `home/map3`

Reserved for another Home(map) state.

## Dashboard

### `dashboard1`

Dashboard/passport overlay assets.

- `passport-open.png`: Open passport base image.
- `change-button.png`: Profile change button image.
- `passport-selected-icon.png`: Selected passport icon image.

## Reserved Folders

- `walk-mode/`: Walk mode and Street View related assets.
- `spots/`: Spot card, discovery, and detail assets.
- `favorite/`: Favorite screen assets.
- `splash/`: Splash screen assets.
- `profile/`: Profile registration/edit assets.

## Naming Rules

- Use lowercase English.
- Use hyphens between words.
- Prefer PNG for map backgrounds, complex illustrations, passport images, and shadows.
- Use code for dynamic text such as distance, coins, user name, profile data, and loading/error messages.
- Use code for simple rectangles, input fields, button hit areas, and overlays when possible.
